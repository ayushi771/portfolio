PROJECT 06

Attendance Module

Shift-aware punch in / punch out, calculated automatically.

A Django + DRF + PostgreSQL attendance system where employees punch in and out, and First Half / Second Half / Total Worked are derived automatically from punch times and each employee's assigned shift — including night shifts that cross midnight.

DjangoDRFPostgreSQL

project preview

A shift-aware attendance system with a live-updating dashboard, an admin-visible late/early/missing-punch-out trail, and dedicated concurrency tests proving race-condition protection under simultaneous load.

what I built

  • Live-updating dashboard — punch card, activity feed, late/early/missing-punch-out alerts
  • Immutable punch log with attendance always re-derived, never edited directly
  • Row-level locking (select_for_update) so simultaneous punches can't create race conditions
  • 25 automated tests covering exact threshold boundaries and dedicated concurrency scenarios
